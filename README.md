# Aesthenda

Main repository: https://github.com/codewhizkid/theaesthendaproject

- `production-app/`: Next.js and Supabase production application foundation.
- `prototype/`: reference UI and workflow sandbox.
- `Every Day Reading Files/`: product and design reference PDFs.
- `START HERE.md`: current project status and documentation map.
- `AESTHENDA_GLOBAL_AUTHORITY.md`: governing project instructions.

The project uses one Git repository at this folder's root. Application code is
still under development; publication here does not indicate production readiness.

Install dependencies separately in each application folder using `npm ci`.
Local credentials belong in ignored environment files and are not stored in Git.

Editable specification sources currently live in the sibling `Aesthenda Documents`
folder and are not included in this repository.
